# OASAriskfactors
Files for "Non-genetic risk factors associated with glenohumeral osteoarthritis-related shoulder arthroplasty" 

Programs used to generate results for: Carey-Ewend AG, Xiaoyi X, Pham V, Keener JD, Yanik EL. "Non-genetic risk factors associated with glenohumeral osteoarthritis-related shoulder arthroplasty." Osteoarthritis and Cartilage Open. 2026. 8(4): 100865. doi: 10.1016/j.ocarto.2026.100865.

 TSA_20240818_documentation= SAS program for generating results in Tables 2, 3, 4, Supplemental Figures, and Supplemental Tables

Datasets derived from the UK Biobank (http://www.ukbiobank.ac.uk/) under Application 27034.
